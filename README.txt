高校教科書購入票 自動生成ツール
================================

【フォルダの中身】
  scripts/gui.py           … 画面（GUI）版　★ふだんはこちらを使ってください
  scripts/main.py          … 文字入力（コマンド）版　※GUIが動かない時の予備
  scripts/saka.py          … 室蘭栄高校 用ロジック
  scripts/touhou.py        … 東翔高校 用ロジック
  scripts/kaisei.py        … 海星学院高校 用ロジック
  scripts/otani.py         … 大谷高校（全日制） 用ロジック
  scripts/shimizuoka.py    … 清水丘高校 用ロジック
  scripts/kogyo.py         … 工業高校 用ロジック
  scripts/printlayout.py   … 学科・コース別リストの印刷レイアウト共通部品
  scripts/shortage.py      … 発注部数の照合
  scripts/masterdiff.py    … 教科書マスターの照合
  settings/後期使用の教科書.txt … 後期に使う教科書の登録（メモ帳で編集できます）
  requirements.txt         … 必要なライブラリ一覧


【まずはパソコンで動かしてみる（実行ファイル化する前に）】

1. Python をインストールする
   https://www.python.org/downloads/ から最新版をダウンロードしてインストールしてください。
   インストール時に「Add Python to PATH」に必ずチェックを入れてください。

2. 必要なライブラリをインストールする
   コマンドプロンプト（またはPowerShell）で、このフォルダに移動して以下を実行します。

     pip install -r requirements.txt

3. ツールを起動する

     cd scripts
     python gui.py

   ウィンドウが開いたら、
     ① 学校と学年を選ぶ（選ぶと必要なファイル欄が自動で切り替わります）
     ② 「参照...」ボタンでExcelファイルを選ぶ
     ③ 「保存先...」で出力先を決める
     ④ 必要なら「印刷用レイアウトも作成する」にチェックを入れ、販売日と注意事項を入力
        ・生徒ごとに購入内容が違う学年（2年・3年）… 1生徒＝1ページ
        ・学科やコースで決まる学年（1年・工業高校）… 1学科（コース）＝1ページ
     ⑤ 「実行」を押す

   学年のところで「発注部数の照合（全学年）」を選ぶと、供給所からもらった
   需要数データと突き合わせて、いま何が何冊足りない／余っているかを出せます。
   販売直前に履修変更が入ったときは、最新の履修データでこれを実行してください。
   名簿が無い学年（1年生・工業高校）は人数の入力欄が出ます。

   「教科書マスターの照合」を選ぶと、供給所データと手元のマスターを比べて、
   定価が変わったもの・新しく入ったもの・無くなったものを一覧にできます。
   年度の切り替え時にお使いください。


【後期使用の教科書について】

学校から送られてくるデータには、後期に使う教科書が混ざっていることがあります。
前期の照合ではまだ発注していないため、そのままだと「不足」や
「手元にしか無いもの」に出てきてしまいます。

settings フォルダの「後期使用の教科書.txt」をメモ帳で開いて、

    栄,新詳地理探究

のように「学校名,書名」を1行ずつ書いておくと、照合のときに
「後期使用（今回の照合では対象外）」として別枠にまとめます。
書名は購入票からそのまま貼り付けてください（全角・半角の違いは自動で吸収します）。

※ exe化した場合は、exeと同じ場所か、その中の settings フォルダに
  このファイルを置いてください。
   という流れです。処理結果は下の「実行結果」欄に表示されます。

   ※ tkinter が入っていないというエラーが出た場合は、Pythonを再インストールし、
     インストール時に「tcl/tk and IDLE」にチェックが入っていることを確認してください。
     （通常はWindows版Pythonに最初から入っています）


【実行ファイル（.exe）にする】

上記の手順でパソコン上での動作を確認できたら、以下の手順で実行ファイル化できます。
以前らくほんnext用のツールを作られた時と同じ流れです。

1. PyInstaller をインストール

     pip install pyinstaller

   ※「pyinstaller は認識されていません」と出る場合は、
     以降の pyinstaller を  python -m PyInstaller  に読み替えてください。

2. scripts フォルダの中で、実行ファイルを作成

     cd scripts
     pyinstaller --onefile --windowed --hidden-import=saka --hidden-import=touhou ^
       --hidden-import=kaisei --hidden-import=otani --hidden-import=shimizuoka ^
       --hidden-import=kogyo --hidden-import=printlayout --hidden-import=shortage --hidden-import=masterdiff gui.py

   ※ settings フォルダは exe には含まれません。dist フォルダに settings フォルダごと
     コピーして、exe と一緒に配ってください。

   --windowed を付けると、黒いコマンド画面が出ずにウィンドウだけが開きます。
   --hidden-import は、gui.py が読み込む各学校のファイルを一緒に取り込むための指定です。

3. dist フォルダの中に gui.exe が作成されます。
   これをダブルクリックすれば、Pythonをインストールしていないパソコンでも動作します。
   デスクトップにショートカットを作っておくと便利です。

   ※ コマンド版（main.py）を実行ファイルにしたい場合は、上記の --windowed を外し、
     gui.py の部分を main.py に変えて同じように実行してください。


【税区分（非課税・課税）の判定について】

教科書は非課税、準教科書（副教材）は課税として計算しています。
学年によっては元のExcelに税区分の列がないため、その場合は
「教科書番号が空欄または『－』のもの＝準教科書（課税）」として自動判定しています。
この判定方法は、税区分が明記されている栄高校（52件）・清水丘高校（48件）の
データと突き合わせて、すべて一致することを確認済みです。

もし判定が合わない教科書が出てきた場合はご相談ください。


【毎年の更新について】

各学校ごとのマスター表（教科書の一覧・価格・必修選択の対応）は、
基本的に「前年の購入票ファイル」からそのつど読み込む仕組みになっています。
そのため、次のいずれかに該当する場合は、コードの修正が必要になる可能性があります。

  - 学校がExcelのシート名・列の並び順を変更した
  - 科目名の表記（略称・全角半角など）が変わった
  - 教科書供給所からのデータで管理する形に切り替える

軽微な変更（価格の更新など）は前年ファイルを差し替えるだけで対応できますが、
フォーマット自体が変わった場合はご相談ください。

各校スクリプトの中には、今年判明した個別のルール（理数科の特別対応、
番号の誤記修正など）がコメント付きで書かれています。次年度に同様の
確認が必要になった際の参考にしてください。
